# PortNew

Разделённая версия портфолио. Открывайте через локальный сервер: из корня репозитория выполните `python -m http.server 8000` и перейдите на http://localhost:8000/ . В VS Code можно запустить Live Server для `index.html`.

- `index.html` — структура страницы и порядок подключения файлов.
- `css/base.css`, `css/home.css` — общие настройки и главная страница.
- `css/categories.css` — категории и прежние общие правила экрана проекта.
- `css/projects.css` — актуальные правила проектов, Art и мобильных категорий. Правила подключены в исходном порядке, поэтому поздние могут уточнять ранние.
- `data/projects.js` — исходные данные проектов и метаданные.
- `data/case-summaries.js` — тексты вкладок проектов.
- `data/categories.js` — состав категорий и фильтры.
- `data/art.js` — названия, описания и пути изображений Art.
- `data/flowpay-screens.js` — изображения экранов FlowPay.
- `js/nebula.js`, `js/animation.js` — настройки, шейдер и анимация фона.
- `js/categories.js`, `js/navigation.js`, `js/gallery.js`, `js/projects.js` — логика категорий, переходов и экранов проектов.
- `js/app-state.js`, `js/events.js` — состояние и обработчики интерфейса.
- `images/art/`, `images/projects/` — локальные изображения.

Скрипты подключаются как обычные JavaScript-файлы: они разделяют общий контекст, поэтому порядок `<script>` в `index.html` важен. Веб-шрифты Google и внешние ссылки требуют интернет; остальные изображения хранятся в проекте.
